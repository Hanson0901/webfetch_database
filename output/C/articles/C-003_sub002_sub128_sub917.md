# 活動訊息 | 經濟部產業園區管理局臺北分局

- 原始網址：https://www.bip.gov.tw/iphw/tpb/activity.do?method=goContent&sn=29883
- 網站：www.bip.gov.tw
- 關鍵字：待人工補充

轉知行政院公共工程委員會訂於115年11月11日（星期三）、11月23日（星期一）及11月30日（星期一）分別於北、南、中部辦理「公共工程植生綠化作業原則指引」交流會，請踴躍報名，請查照。
活動時間
  			
  				2026/11/03 ~ 2026/11/30
				
       
活動內容
為落實正確種樹理念，工程會編撰「公共工程植生綠化作業原則指引」，並辦理旨揭交流會，向各機關、地方政府及各界說明指引重點內容，並蒐集實務意見，作為後續推廣及精進之參考。
