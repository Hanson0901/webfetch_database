# 經濟部產業園區管理局- 推薦區內事業創櫃板登錄

- 原始網址：https://www.bip.gov.tw/page.aspx?pageid=484741ef74fba199
- 網站：www.bip.gov.tw
- 關鍵字：待人工補充

申請推薦區內事業創櫃板登錄
業務說明：輔導轄內具創新、創意及發展潛力之未公開發行股票之企業營運。
檢具文件：1.營業計畫書
2.最近一年度之財務報表及近期財務相關資料
3.公司、董事、監察人、持股百分之十以上大股東及總經理，暨前開對象為法人之董事、監察人、持股百分之十以上大股東最近二年內如有遭檢調單位搜索，暨所發生繫屬中或判決確定之訴訟、非訟、行政處分、保全程序或強制執行事件者，其說明及相關聲明或佐證文件
4.負責人無公司法第30條情事之聲明書
5.申請書件無虛偽隱匿聲明書
6.推薦在區內營業之事業申請登錄創櫃板作業須知及申請書
7.依其他相關規定應檢繳之文件
法令依據：經濟部產業園區管理局推薦在區內營業之事業申請登錄創櫃板作業須知
辦理時限：1個月內審查核定
