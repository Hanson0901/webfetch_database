# 虛擬農遊－農業易遊網

- 原始網址：https://ezgo.ardswc.gov.tw/zh-tw/immersive/
- 網站：農業易遊網
- 關鍵字：待人工補充

花蓮的光復鄉昔日被稱為馬太鞍，
為阿美族語中樹豆 Fata'an 的意思，
擁有花蓮境內最大的濕地及多元的原民文化，
透過老鷹的視角、單車騎行的畫面與豐富的導覽，
以 360 度超高畫質全景照片呈現，
從自然生態、復育物種到餐桌旅行，帶你一起遨遊馬太鞍的精彩！
在清澈的芙登溪中，體驗道地的美式捕魚巴拉告，看著當地阿美族如何利用竹筒、九芎木、山棕葉等打造魚蝦的住家，以適度捕撈的傳統捕魚法，傳遞居民如何與自然共存的生活智慧。
一同踩踏雙輪，以單車漫遊穿梭馬太鞍休閒農業區，觀賞幽靜的溼地風光，在每年5至8月還能瞧見蓮荷齊放的勝景，最後再到大農大富平地森林園區，欣賞楓林小徑之美，與森林動物居民不期而遇。
從自己採摘野菜、認識溪裡水菜與溪蝦到親手做盛飯器皿，透過做中學深刻認識就地取材的飲食文化，在私房料理中嘗到天然的美味，透過第一人稱視角，來體驗當地最沁涼的流水席吧！
跟著我們的視野
一同探索國家級內陸濕地
馬太鞍濕地屬於天然的內陸濕地，地下水源豐沛，擁有清澈的湧泉，透過數位孿生，你可以實際走進馬太鞍濕地的木棧道中，自由探索濕地生態與部落文化，聆聽由青蛙們組成的交響樂，以各種角度觀看濕地之美。
位於雲林口湖鄉的金湖休閒農業區，是台灣重要的食材產地，
不僅串聯台17線的濱海風光，透過鳥瞰絕美的椬梧滯洪池與成龍濕地，
再到地面走入當地，藉由自行車悠遊小鎮社區與認識生態養殖水產的秘辛，
從親手摸蛤、抓蝦到品嘗產地直送的料理，帶你深度感受這片漁鄉的純樸與豐饒。
騎乘單車穿梭於素有「小日月潭」美稱的椬梧滯洪池，探索週邊的湖口濕地認識紅樹林生態，或造訪由桑田變滄海的成龍濕地，觀賞運用生態工法打造的地景藝術作品，在臨海園欣賞夕照蚵田，感受海口獨特的人文氣息。
跳進馬蹄蛤主題館的池水中體驗「摸蜆仔兼洗褲」的沁涼，認識貝類生長的過程；或是走進好蝦冏男社，拿起傳統四角蝦網與八卦網，親手體驗捕撈無毒白蝦的成就感，透過做中學的食農教育，深刻體會友善養殖的辛勞與樂趣。
來到烏魚子的故鄉，親眼見證澄黃魚子在冬日暖陽下曝曬的壯觀景象，品嘗濃縮大海鮮味的「烏金」美味，在金湖商圈、口湖遊客中心享用結合在地時令水產的料理，或到大啖邪惡鰻魚飯，從產地直達餐桌，讓舌尖享受最新鮮的海味與甘甜。
沿著水岸騎行
飽覽水鳥生態與絕美夕陽
生態島位在椬梧滯洪池中，擁有平緩的步道及豐富的自然生態，適合散步或騎單車悠遊，藉由數位孿生的自由探索，帶你看見秋冬來訪的鸕鶿與小白鷺等水鳥，認識當地植物，感受滯洪池的蓬勃生機。
台東縣池上鄉不僅擁有享譽全台的優質池上米，
更有如畫般的稻浪地景，跟著我們從上空俯瞰絕美的稻田景觀，
從日式米倉造型的車站出發，
開始走訪在地老米廠的故事與豐收的美味，
邀請你放慢腳步，感受這份純樸且濃厚的米鄉意象，
體驗從產地到餐桌的深度旅程。
騎上單車悠遊池上米鄉休閒農業區，走訪伯朗大道、天堂路或騎行池上環鄉自行車道，享受大坡池與稻田的遼闊視野，沉浸於翠綠或金黃稻浪交織的絕美地景，感受無比放鬆的自由。
從推動古早土礱碾米、編織舒壓稻香錘到親手製作爆米香，透過五感手作傳承惜物的農事智慧，在米香酥脆甜美的滋味中體驗古早零嘴的魅力，感受最道地的農家溫度吧！
池上不僅產米，更是化身藝術舞台，「縱谷大地藝術季」將裝置藝術散落各處，「秋收稻穗藝術節」則以黃金稻田為幕邀請藝人及知名團體演出，兩大盛事讓縱谷化身天地劇場，讓人在自然中感受人文溫度。
跟著我們的腳步
探索池上冠軍米的誕生
金色豐收館位在池上鄉農會觀光工廠內，是一座結合感性休閒與知性教育的場館，透過數位孿生，你可以穿梭在文物區見證傳統農具智慧，探索稻米科學的奧秘，深入了解稻穀如何脫殼成為白米的奇妙旅程，更可以認識池上如何成為冠軍米的美味秘密。
