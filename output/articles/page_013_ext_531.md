# 經濟部產業園區管理局- 楠梓科技產業園區從業員工育樂活動中心場地規定及收費標準表(修訂版)

※如先前用原收費標準租借之單位，後續租借場地時，將以「差額扣抵」的方式辦理抵用，謝謝※
預約系統
1. 系統開放1個月內之場地預約申請，並請於3日前完成預約申請(如11月21日僅可預約11月24日至12月21日的日期，依此類推)。
2. 如需提早入場或延後離開請於預約時段成功後，再行向承辦人電洽或Email備註。
3. 預約成功後請於繳款聯單開立後3日內完成繳費事宜。
4. 如需臨時入場使用，請先行與承辦人接洽確認場地事宜，並於開單後立即完成繳費，謝謝。
5. 因故無法使用，需於使用日前7天（日曆天）申請退費，扣除所繳費用10％(手續費）後，退還剩餘所繳費用；逾期不予受理，所繳費用不予退還。
6.「嚴禁曾涉兒少保護案件者報名本中心課程，或租借綜合球場使用，如經通報查實，本中心得直接請離並要求不得進入」。
