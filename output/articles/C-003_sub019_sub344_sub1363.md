# 經濟部產業園區管理局- 產業園區下水道系統營運中心及冷卻水廠 113年度營運績效評定結果

- 原始網址：https://www.bip.gov.tw/info.aspx?pageid=35c6d56cf2bc1f47&cid=a44c476a1be77aaa
- 網站：www.bip.gov.tw
- 關鍵字：待人工補充

依據本局「產業園區下水道系統營運中心及冷卻水廠營運績效評定作業原則規定」，為落實監督管理所轄工業區下水道系統營運中心、冷卻水廠及簽訂該營運中心投資契約之民間機構，本於公平、公開程序及符合公共利益、公平合理原則，114年針對營運中心113年營運績效辦理評定作業。
