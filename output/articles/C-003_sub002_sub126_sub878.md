# 首頁 | 經濟部桃園幼獅產業園區服務中心

- 原始網址：https://www.bip.gov.tw/iphw/taoyuanyouth/
- 網站：www.bip.gov.tw
- 關鍵字：桃園

| 一 | 設立緣起：桃園幼獅產業園區乃是蔣故總統 經國先生為了幫助青年創業、解決設廠用地取得困難的問題，於民國58年10月指示籌設一個專供青年創業的產業園區。 | 
| 二 | 成立時間：本區創建歷經青輔會、經濟部產業園區管理局及救國團負責邀請有關單位多次會商，才於61年5月8日順利完成開發工作。 | 
| 三 | 土地面積：產業園區的土地面積達61.57公頃。除高速公路用地佔9.06公頃之外，其餘52.51公頃全部為工業用地。其中，廠房佔地達38.62公頃。 |
